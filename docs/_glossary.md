*[OME-Zarr]: Open Microscopy Environment next-generation file format, storing large multi-dimensional images and their metadata in Zarr
*[NGFF]: Next Generation File Format — the OME specification OME-Zarr implements
*[HCS]: High-Content Screening — imaging organised in a multi-well plate layout
*[FOV]: Field Of View — one position the microscope acquired, possibly as several files
*[ROI]: Region Of Interest — a bounded region of an image, stored in a table
*[MIP]: Maximum Intensity Projection
*[Fractal]: A framework for processing bioimaging data at scale, which these converters plug into as tasks
*[Zarr]: A chunked, compressed, N-dimensional array storage format
*[TiledImage]: The composite object representing one complete image assembled from tiles
